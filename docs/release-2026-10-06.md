The medians meet the 75-point allowance for this immersive 3D site. They do not establish consistent 90+ performance or sub-2.5-second LCP. Field INP is not measured. Further speed improvement is a technical opportunity, not an owner content task; do not describe these numbers as a perfect score.

An earlier single run scored 85/93; repeated measurements supersede that headline. An embedded mobile-image experiment scored median 73/80, increased the overall payload and was removed. The active release retains external responsive images. Independent checks confirm compressed HTML and static JavaScript delivery. The local Windows Chrome path showed different delivery behavior and lower scores; no user-agent-specific optimization was added.
