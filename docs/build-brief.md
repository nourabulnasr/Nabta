=== PROJECT ===
Nabta (نبتة, "a sprout") — an AI consultancy brand + portfolio site for
an AI engineer in Egypt. Aesthetic target: collabcapitolium.fr — dark,
editorial, award-tier motion. Deployable to Vercel later (no domain yet
— local preview only for now).

Stack: Next.js (App Router, TypeScript) + Tailwind + Framer Motion.
Phases 1–3 use NO WebGL/3D/shaders (Framer + CSS only — this gets ~80%
of the Capitolium feel with none of the quota/perf risk). WebGL is
Phases 4+, each its own checkpoint, added only after the site ships.
